\subsubsection{Compute}
Most of the lab exosquelleton run on beaglebone black
While theses support CAN natively, and run linux, the SSH connection was VERY slow and thus was rejected. The main selling point was the real time coprossor (understand a beefy MCU that run alongsinde the main CPU for time critcal application) but this require custom code and the performance benefit are still to demosntrate.

A raspberry pi 2 b+ that was laying around was used instead as the author had much more experience with theses. It did require to buy a CAN hat over SPI. another hat with an accelerometer was bought (raspberry pi sense hat) for the ease of integration. 

mention here or later the need to check the mapping when stacking the two hats.

Need to documen the test for loop frequency and jitter but main result is that we can have a can loop at 200 Hz but and that the raspberry pi is MUCH more powerful than the bleagle bone. which is very convenient for development (we host a wifi hostpoint so we can connect to the robot, we host a web interface to control the robot to simplify the manipulation)

\subsection{Robot modelling}

CAD matrix, validate accuraccy and orietnation with reference frame.
